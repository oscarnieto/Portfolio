Publicar los cambios

La web se publica desde GitHub. Para que tus cambios sean visibles para todo el mundo:

  1. Pulsa «Descargar configuración». Se descargará el archivo site-config.js.
  2. Abre la carpeta data del repositorio en GitHub (rama main).
  3. Pulsa Add file → Upload files, arrastra el archivo descargado y confirma con Commit changes. Al reemplazar el archivo existente, la web se reconstruye sola.
  4. En 1–2 minutos los cambios estarán publicados. Fuerza la recarga con Ctrl/Cmd + Shift + R si no los ves.

Las imágenes subidas desde el ordenador viajan dentro de la configuración (comprimidas a máx. 1600 px). Si son muchas o muy pesadas, súbelas como archivos a una carpeta img/ del repositorio y usa su ruta (img/foto.jpg) en el campo URL.

Tu borrador seguirá guardado en este navegador hasta que pulses «Restablecer».
